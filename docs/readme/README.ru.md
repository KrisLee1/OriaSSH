## Возможности

### 🔗 Управление туннелями на карте

- Карта показывает, как локальные порты связаны с SSH-хостами. Запускайте и останавливайте правила по одному или группами, следите за состоянием туннелей, числом активных соединений и трафиком.
- Выберите хост из конфигурации SSH или добавьте его вручную. Доступны вход по паролю, закрытому ключу или через системный SSH-агент, а также подключение через несколько промежуточных хостов (ProxyJump).
- Сохраните правило, чтобы в следующий раз открыть внутренний сайт с карты или подключить клиент базы данных к локальному порту.

### ⚙️ Удалённые сервисы

- Сохраните в шаблоне команды запуска, остановки и перезапуска сервиса, проверки состояния и просмотра журналов. Свяжите шаблон с правилом перенаправления, чтобы выполнять команды из меню сервиса.
- Если сервис нужно предварительно запустить, задайте команду запуска и проверку готовности. При запуске с подключением виден результат каждого этапа вплоть до открытия туннеля.

### 💻 Локальные и SSH-терминалы

- Переключайтесь между локальными и удалёнными сеансами во вкладках. Используйте подсказки при вводе, нажимайте ↑ для просмотра истории или находите по ключевому слову команды, сохранённые в других сеансах.
- Редактируйте многострочные команды с помощью Shift+Enter. При смене каталога черновик сохраняется. Длинный вывод можно свернуть, а команду и её результат — скопировать по отдельности.

### 📁 Передача файлов

- Откройте локальный и удалённый каталоги рядом и перетаскивайте файлы между панелями для отправки или скачивания целыми группами. Чтобы передавать файлы между SSH-хостами, откройте свой хост в каждой панели.
- Следите за ходом передачи в фоновой очереди, приостанавливайте, возобновляйте или отменяйте задачи. Файлы можно просматривать, а текст — редактировать прямо в приложении.

### 🖥️ Удалённый рабочий стол VNC

- Откройте рабочий стол в отдельном окне через SSH-туннель с перенаправлением VNC. Доступны полноэкранный режим, масштабирование и копирование текста в обе стороны.
- В том же окне можно открыть SSH-терминал или передать файлы по SFTP. Передача уже добавленных в очередь файлов продолжится после закрытия окна.

## Быстрый старт

В этом примере веб-сервис уже работает на порту 3000 SSH-сервера. Чтобы открыть его в браузере на своём компьютере, выполните три шага.

1. Откройте OriaSSH и выберите **Добавить хост**. Выберите хост, найденный в конфигурации SSH, или введите его параметры вручную. Поиск только читает конфигурацию и не подключается автоматически.
2. Перетащите указатель от края карточки локального компьютера на свободное место карты. Выберите хост и локальное перенаправление (L). Задайте локальный адрес `127.0.0.1:13000` и целевой адрес `127.0.0.1:3000` на SSH-сервере.
3. Выберите **Сохранить и запустить**, пройдите аутентификацию по запросу и проверьте отпечаток сервера при первом подключении. Когда появится состояние **Прослушивание**, откройте `http://127.0.0.1:13000` в локальном браузере.

В следующий раз достаточно запустить сохранённое правило. Если страница не открывается, проверьте, работает ли удалённый сервис на целевом порту. [руководство по диагностике (китайский)](../USAGE.md#查看状态与排查问题)

### Выбор способа перенаправления

| Способ | Когда использовать | Как получить доступ к сервису |
| --- | --- | --- |
| **L · Локальное перенаправление** | Доступ с этого компьютера к веб-приложению, базе данных или VNC на сервере | Подключитесь к локальному слушающему порту, который передаёт запросы удалённому сервису по SSH |
| **R · Удалённое перенаправление** | Доступ с сервера к сервису разработки на этом компьютере | Подключитесь к слушающему порту на сервере, который передаёт запросы локальному сервису по SSH |
| **D · Динамическое перенаправление** | Доступ через SSH-хост к нескольким адресам внутренней сети | Открыть отдельный прокси-браузер через меню или настроить другой клиент для локального SOCKS5 |

Если файл OriaSSH уже подготовлен, импортируйте его в разделе файлов конфигурации в настройках, проверьте содержимое и настройте собственную аутентификацию перед запуском. Импортированные шаблоны сервисов нужно отдельно проверить и разрешить. См. [готовая конфигурация (китайский)](../USAGE.md#使用现成配置).
