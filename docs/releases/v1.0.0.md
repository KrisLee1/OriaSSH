## OriaSSH 1.0.0

OriaTunnel 更名为 OriaSSH。原有用户可从「关于」检查更新，继续使用已有工作区、系统凭据库和偏好设置。旧版导出的配置文件仍可导入。

- **连接图**。主机卡集中显示服务与转发。从服务向「此电脑」拖线即可创建本地转发，在端口浮卡中查看实际监听地址、连接状态和流量。顶栏支持按名称或端口搜索定位。
- **SSH 账号**。一台主机可以关联多套凭证，也可跨主机复用。在主机卡切换账号后，新连接使用所选身份，已有连接继续使用原账号。主机日志可按身份、服务和转发筛选。
- **服务管理**。服务可以使用前台命令或 systemd 托管。通过「启动并连接」按顺序启动服务、执行已配置的检查并建立转发，命令输出和服务日志可分别查看。
- **迁移与分享**。在「设置 → 配置文件」中迁移整个工作区，或单独选择主机、服务和转发分享。导入时可复用已有主机并映射登录资料，分享包不包含密码或私钥正文。
- **终端与文件**。交互终端按当前 Shell 补全常用子命令、选项和路径，改善缩放后的末行显示。大工作区的端口搜索和文件多选更快，目录读取失败后可重试。
